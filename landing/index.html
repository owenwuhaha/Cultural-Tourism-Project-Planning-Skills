🚀 快速开始

零依赖，纯Python，一键运行 — 打开终端，输入以下命令：

$ git clone https://github.com/owenwuhaha/Cultural-Tourism-Project-Planning-Skills.git
$ cd Cultural-Tourism-Project-Planning-Skills/scripts
# 工具总控台 — 交互式菜单
$ python planner-toolkit.py

# 或者直接运行单个工具
$ python generate-plan.py
$ python catchment-heatmap.py --demo
$ python competitive-analysis.py
